    Atur Target

    Satu baris target = satu periode + satu cakupan. Menyimpan periode dan cakupan yang sama akan mengganti nilai lama. Isi Berlaku sampai untuk menerapkan nominal yang sama ke beberapa bulan sekaligus (maks 12). Pilih nama agen pada Untuk bila target ditetapkan per agen.

    Daftar Target

    Bila target toko tidak diisi tetapi target agen ada, target toko dihitung dari jumlah target para agen.
